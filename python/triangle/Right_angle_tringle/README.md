
# Right-Angled Triangle Star Patterns in Python

This repository contains a collection of Python scripts designed to print various geometric star (`*`) patterns using loops. It is a practical resource for mastering control flow, nested loops, and string manipulation in Python.

## Features

* **Multiple Layouts**: Includes  Right-Angled Triangle,Reversed-Right_Angled Tringle.
* **Dynamic Sizing**: All patterns adjust dynamically based on user-defined row inputs.
* **Beginner Friendly**: Clear, unoptimized logic perfect for educational purposes.

## Core Patterns Included

### 1. Right-Angled Triangle
~~~
 * 
 *  * 
 *  *  * 
 *  *  *  * 
 ~~~
### 2. Reversed-Right_Angled Tringle
~~~
 *  *  *  * 
 *  *  * 
 *  * 
 *
~~~
## Code Logic Breakdown

Most patterns rely on nested `for` loops using the `range()` function:
* **Outer Loop**: Controls the number of rows (vertical axis).
* **Inner Loop 1**: Handles the leading spaces required for alignment.
* **Inner Loop 2**: Handles the actual printing of the star (`*`) characters.
